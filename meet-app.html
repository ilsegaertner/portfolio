Meet App

A progressive web app for finding developer events by city, written test-first.

Year
2023
Stack
React, Recharts, Google Calendar API, AWS Lambda, Jest, Cucumber, Puppeteer
Links
Live Code

Meet App lists upcoming developer events in cities around the world. You filter by city, choose how many events to show, open an event for its details, and see how the events are distributed in two charts. It installs like a native app on a phone or a desktop and keeps working without a connection.

Tests first

I wrote this project test-first: unit and integration tests in Jest, acceptance tests with Cucumber, and end-to-end runs in Puppeteer. Coverage is above 90 percent.

Sign-in without a server

The events come from the Google Calendar API, which requires OAuth 2. The app has no server of its own, so the token exchange runs in AWS Lambda functions.

Offline

A service worker caches the app and its data, so the list still opens with a weak connection or none at all.
