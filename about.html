About

I’m a frontend developer based in Berlin. I work at OKAPI:Orbits, where I build Angular applications for the space industry. Before that I was at 4Cast in Potsdam, on a React and TypeScript application for managing machine-learning data. There I built dashboard features and a component library documented in Storybook, and set up the tests with Vitest and Playwright.

I came to this by a long route. For about fifteen years I worked in electronic music and visual art, and I taught. I studied multimedia art in Salzburg, then fine art and English in Hamburg. Most of that work came down to taking something from a first idea to a finished object, sometimes alone and sometimes with other people. I still build software that way.

In 2023 I started a full-stack course at CareerFoundry and built my first applications there: a REST API, clients in React and Angular, a progressive web app, and a mobile app in React Native. Since then I have concentrated on the frontend, on component architecture, typing and testing, and on the details that decide whether an interface is pleasant to use.

Tools

I write TypeScript every day, at the moment in Angular and before that in React. I style with Tailwind or Sass and test with Vitest, Playwright and Jest. I have also built with React Native, Node.js, Express, MongoDB and Firebase.
